# \#Actividad 2: Configuración de herramientas (Git y GitHub)

# 

# Este repositorio documenta el proceso de la actividad, que consiste en usar comandos básicos de Git y GitHub para registrar y publicar cambios en varios documentos.

# 

# Proceso seguido

# 

# 1\. Cuenta en GitHub: me registré en la plataforma para alojar el repositorio remoto.

# 2\. Instalación de Git: descargué Git desde su página oficial y configuré mi nombre y correo con `git config`.

# 3\. Creación del repositorio: cree un repositorio nuevo en GitHub.

# 4\. Clonación: lo copié al computador con el comando `git clone`.

# 5\. Documentos del tutorial de Git: a partir del libro `Pro Git` (https://git-scm.com/book/es/v2) elaboré 10 archivos de Word, uno por cada capítulo (`Git\_cap\_1.docx` a `Git\_cap\_10.docx`). Luego exporté cada uno a formato PDF, y quedaron 10 archivos `Git\_cap\_1.pdf` a `Git\_cap\_10.pdf`)

# 6\. Carga al repositorio: al terminar cada capítulo subí su archivo de Word y su PDF con el ciclo `git add` para cargarlo, `git commit -m " Aprobado cap N"` para nombra la aprobación y `git push origin main` para subirlo a GitHub, con un mensaje de confirmación descriptivo en cada uno de los casos.
